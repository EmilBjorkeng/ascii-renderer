## Running

Requires a recent stable Rust toolchain (install it with [rustup](https://rustup.rs)).

```bash
git clone https://github.com/EmilBjorkeng/ascii-renderer.git
cd ascii-renderer
cargo run --release
```

The picture is 80 × 40 characters (configurable in the code).

## How it works

The code is based on what I learned while creating [Software-Rasterizer](https://github.com/EmilBjorkeng/Software-Rasterizer),
but scaled down and specialised for rendering a spinning donut. And, of course, it renders in the terminal.

Built with [glam](https://crates.io/crates/glam) for vector and matrix maths.
